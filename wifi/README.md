# RTL8189FS Wi-Fi source

E70Q10의 Realtek v4.3.24.10_24994.20171103 드라이버 소스와 RIDI 설정을 보존합니다.
`rtl8189fs/`는 원본 GPLv2 고지를 유지하고, `COPYING`과 출처/파일 해시를 포함합니다.
공개 Tolino Epos 커널 배포본과의 차이는 `RIDI-adaptations.patch`에 기록합니다.
기존 `prebuilt/8189fs.ko`는 로컬 빌드 결과와 해시가 같으며 순정 독점 모듈로 분류하지 않습니다.
현재 커널을 변경했다면 예전 모듈의 ABI 호환성을 가정하지 말고 함께 다시 빌드해야 합니다.

메인 환경 구성 후 `ridi-build-support/build-wifi.py --check`로 입력을 확인하고,
먼저 제품 커널을 빌드한 뒤 인자 없이 실행합니다. 소스는 출력 폴더에 복사해서 빌드하며,
원본 드라이버 폴더나 예전 prebuilt를 자동 교체하지 않습니다. 새 모듈 경로를 확인한 뒤
제품의 vendor 모듈 입력을 갱신하고 boot/vendor를 함께 준비하세요.
이번 소스 보존 작업에서 새 모듈의 실제 컴파일이나 실기기 검증은 실행하지 않았습니다.
